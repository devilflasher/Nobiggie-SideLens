# 0.1.4 追问与主题补查

- 追问复用现有队列、凭据、OAuth 身份、取消与超时处理。新增消息只接受原有可信顶层 X 端口；角色、模式、问题、分析和对话总长有界，拒绝 system 角色注入及未完成的上下文轮次。
- 用户问题、原分析及历史回复均不进入系统指令，也不视作独立证据。原帖上下文与既有输出作为不可信输入处理。建议使用现有结构化文本通道并验证恰好三个不同、长度受限的字符串。
- 原生点击才允许发起追问、建议重试或建议点击。表单的脚本 requestSubmit 被阻止；自动建议只在用户主动请求的分析或追问成功后生成。
- 只有初次建议进入现有有界缓存；追问、含聊天上下文的建议与相关诊断不持久保存、不写历史。缓存仍按账号和模型配置隔离。
- 外观值由可信 worker 写入，仅允许 light/dim/dark，不放宽 TRUSTED_CONTEXTS 存储访问。社区 PNG 本地打包，外链固定 HTTPS，使用 noopener/noreferrer；无新增主机权限、远程脚本或遥测。

本版 972 项自动化测试和 52 项隔离浏览器检查通过；真实提供方的生成质量和实际安装后的运行仍需用户验收。

# SideLens 0.1.0 安全审查

2026-10-27。范围：上游源码及本次改造；基线 5cfa125f9000866c1719afc452d1867ef37280bf。

## 检查与加固

| 领域 | 代码与结论 |
| --- | --- |
| 权限 | manifest.json 仅 storage、alarms；固定 X/xAI host，回环地址为可选权限。无 all_urls、cookies、浏览器历史或 externally_connectable。 |
| 消息边界 | background.js 长连接统一经过 trustedFeed，补充 sender.id、frame 和 tab.id 校验，拒绝非对象消息。凭据及设置操作保留 trustedUI。 |
| 用户点击 | content.js 拒绝 isTrusted=false 的分析、刷新与评论点击，防止网页脚本通过开放 shadow DOM 合成操作。草稿沿用原有可信点击校验。 |
| 凭据 | key-store.js 与 oauth-provider.js 沿用 AES-GCM、随机 IV、独立用途认证数据；不可导出密钥位于 IndexedDB，明文不下发给推文脚本。 |
| 网络 | api-provider.js、oauth-provider.js、build-transport.js 使用固定官方端点或 loopback；无新增中转、遥测或远程脚本。 |
| 内容渲染 | markdown-renderer.js 构建有限 DOM 节点，不把 AI HTML 写入 innerHTML。HTML/图片 token 作为文字显示；仅接受无内嵌凭据的 http/https 链接，使用 noopener noreferrer。 |
| 缓存 | local/session 都设为 TRUSTED_CONTEXTS。按配置及 OAuth 身份区分；凭据变更清空。串行写入与 epoch 避免迟到回写，过期、无效和未完成结果不复用。 |
| 图片与草稿 | 主动核查才读取图片字节，最多四张 PNG/JPEG、合计 8 MiB；草稿不进入缓存、历史或诊断。 |
| 供应链 | 无运行时 npm 安装；Marked 随包并保留许可。打包使用文件白名单、符号链接和嵌入凭据检查，CI action 固定提交。 |

## 当前边界

- 缓存和历史不加密，可包含你点击的非公开帖子；不上传、不使用同步。完整浏览器配置和备份按敏感资料保管。
- 本机加密不能抵御设备被控制，或密文与 IndexedDB 同时泄露。
- OAuth 沿用上游共享客户端和提供方协议，账号资格、额度及模型访问未用真实账号验证；原重试策略可能产生额外费用。
- 本机 Build 是独立进程，浏览器断开不保证远端工作停止；继续依赖取消确认。
- 真实 X 的不同 DOM/语言/账号布局、正式扩展实装和真实模型输出尚未验证。本记录只陈述源码检查、自动化测试和隔离模拟证据。
