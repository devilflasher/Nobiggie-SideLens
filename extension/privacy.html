隐私说明

Nobiggie SideLens 0.1.6 · 2026-10-27

点击后才分析

浏览 X 时，SideLens 只寻找推文容器并挂载按钮。主动点击后，才提取该帖正文、作者、原帖链接、可用图片及引用上下文，交给你选择的 Grok 连接处理。滚动不会自动启动分析，也不会批量记录浏览过的帖子。私信页与独立 Grok 页面不参与。

草稿核查保留原项目能力，只有主动点击核查才发送草稿文字及支持的附图。最多四张 PNG/JPEG、合计 8 MiB；草稿结果只在运行内存保留，不写入缓存或历史。SideLens 不自动发帖、回复、点赞或转发。

本机缓存与历史

成功完成的分析在受限的 chrome.storage.local 中保存，缓存键为 sidelensCache。有效期为生成后 24 小时，最多 160 条、约 4 MB；达到容量上限会清理旧记录。刷新页面、重启浏览器后均可复用。缓存按帖子、连接来源、OAuth 身份、模型、语言、搜索、推理和实际提示词区分。重新分析会跳过对应缓存。

开启历史记录后，只记录你主动打开分析的推文及已有结果，最多 1,000 条、约 6 MB，按最后打开时间保留 24 小时。历史与缓存分别清除。缓存和历史不加密、不使用浏览器同步，也不作为集合上传。可能包含你点击过的非公开帖子；请按敏感资料保管浏览器配置与备份。

缓存到期后不再复用；启动与写入时清理。浏览器未运行时不保证精确到点删除。清除或更换 API Key 会清除缓存；OAuth 身份不同的结果相互隔离。

回复草稿

只有你点击生成回复，才会把原帖、分析、最近三轮追问及所选语气、方向和目标字数发送给当前提供方，产生额外用量。回复不额外搜索、不自动发布；草稿和讨论只留在当前页面内存，不进入缓存、历史或持久诊断。你可以编辑文本并点击复制；只有点击复制时才写入剪贴板。

追问、问题建议与外观

初次分析完成和每次追问回答后，会使用当前连接及模型额外生成 3 个问题建议，产生提供方用量。初次建议进入现有有界缓存，复用时不重复生成。追问发送原帖、初次分析、最近三轮问答及当前问题；聊天及含聊天上下文的后续建议只保留在当前页面内存，不写入缓存、历史或持久诊断，刷新后不恢复。

本机保存最近一次观察到的 X 外观（亮色、暗蓝或纯黑），供扩展页面使用。社区 Logo 随包存放；只有点击社区按钮时才打开 nobiggie.xyz/chat。

凭据与服务商

沿用三种连接：Grok 订阅 OAuth、API Key、本机 Grok Build。API Key、OAuth 刷新 Token 和本机连接码使用分开的 AES-GCM 加密记录；不可导出的密钥保存在扩展 IndexedDB。访问 Token 与会话 Key 只保留于受限会话存储。完整浏览器配置或设备被控制时，本机加密不能提供隔离。

API/OAuth 请求直连 xAI 官方端点；本机模式连接你启动的固定 127.0.0.1 服务。SideLens 没有额外分析中转或遥测端点，不读取 X 的密码或认证 Cookie。模型权限、计费、日志和数据保留由提供方及你的账户设置决定；store:false 不等于提供方零保留。

本机 Build 的官方进程独立于浏览器运行。断开浏览器连接不保证任务停止；原项目的取消确认和错误提示继续适用。网页和 AI 文本均作为不可信内容处理，来源链接由你选择打开。

Privacy at a glance

SideLens analyzes a post only after an explicit click. Scrolling does not start analysis or collect a browsing-history feed. Selected context goes directly to xAI or the user's loopback Grok Build service. There is no additional SideLens relay or telemetry.

Completed results stay in trusted local extension storage for up to 24 hours, bounded to 160 entries / approximately 4 MB, surviving reloads and browser restarts. Optional history contains only posts explicitly opened for analysis, bounded to 1,000 entries / approximately 6 MB for 24 hours. Both stores are unencrypted and do not use sync; they are cleared independently. Drafts and follow-up conversations remain in runtime memory. Follow-up questions include the original post, initial analysis and up to three recent question/answer pairs. Three generated question suggestions after each answer consume additional provider usage; only initial suggestions are cached. Reply drafts use the post, analysis, three recent discussion exchanges and selected writing preferences only after an explicit click; they consume provider usage, remain in page memory and are never automatically published. Copying requires a user click. The last observed X appearance is stored locally. The community link opens only on a user click.

Remembered credentials use separate AES-GCM records and non-exportable keys in IndexedDB. This cannot protect a compromised device or an entire copied browser profile. Provider billing and retention still apply. SideLens is an independent MIT derivative of SuperX, not affiliated with X, Grok or xAI.
